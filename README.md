# 🎮 Games

Three games made in Python:

## 1. Tic Tac Toe (GUI) — `Tic Tac Toe Final.py`
A two-player game drawn with the `turtle` module. Player A is circles and Player B is crosses. Take turns clicking a square. The game announces the winner, or a tie when the board is full.

## 2. Rock Paper Scissors — `Rock Paper Scissors Game.py`
Play against the computer in the terminal. Type rock, paper or scissors, then choose whether to play another round.

## 3. Random Guessing Game — `random_guessing_game.py`
Pick a range of numbers, and the computer chooses a secret number in it. You guess, and it tells you to go higher or lower until you get it.

## How to Run
You need Python 3. No extra libraries are needed (`turtle` comes with Python).

```bash
python "Tic Tac Toe Final.py"
```
